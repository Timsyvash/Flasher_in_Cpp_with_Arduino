# 🚦 Мультизадачний світлодіодний маяк (Асинхронний таймер на Arduino)

Цей проєкт демонструє концепцію **справжньої багатозадачності** на мікроконтролерах. Замість блокуючих затримок `delay()`, які повністю зупиняють роботу процесора, тут реалізовано незалежну роботу трьох світлодіодів за допомогою неблокуючого таймера `millis()`.

Кожен світлодіод працює за власним розкладом, абсолютно не заважаючи іншим:
* **Червоний світлодіод:** Блимає у швидкому темпі (кожні 200 мс).
* **Зелений світлодіод:** Блимає спокійно (кожні 1000 мс).
* **Синій світлодіод:** Плавно загоряється і згасає за допомогою ШІМ (крок зміни кожні 15 мс).

## 🛠️ Компоненти
* Мікроконтролер **Arduino Mega 2560** (або будь-яка інша Arduino)
* Макетна плата (Breadboard) та дроти
* 3 світлодіоди (Червоний, Зелений, Синій)
* 3 резистори (220 Ом)

## 🔌 Схема підключення
* **Червоний світлодіод:** Анод ➡️ Резистор 220 Ом ➡️ Цифровий пін `7`
* **Зелений світлодіод:** Анод ➡️ Резистор 220 Ом ➡️ Цифровий пін `8`
* **Синій світлодіод:** Анод ➡️ Резистор 220 Ом ➡️ Цифровий ШІМ-пін `9`
* **Катоди всіх світлодіодів:** ➡️ Спільна шина `GND`

## 🧠 Особливості коду
1. **Роздільні таймери:** Створено три незалежні змінні `last_time_red`, `last_time_green` та `last_time_blue`. Це дозволяє процесору паралельно стежити за часом для кожного завдання.
2. **Інверсія стану:** Використано конструкцію `!digitalRead(pin)`. Вона зчитує поточний стан піна і миттєво змінює його на протилежний без створення додаткових змінних.
3. **Плавне згасання (Fade) без циклів:** Для синього світлодіода яскравість змінюється покроково (+5 або -5) при кожному спрацьовуванні мікротаймера на 15 мс. Це позбавляє від необхідності використовувати блокуючі цикли `for`.
